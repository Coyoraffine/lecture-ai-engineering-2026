# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第1回の `app.ask` は、講座のことを知らないまま「初級・中級・上級」の3段階と一般論で答えていた。エージェントは用語集のとおり、基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）の3段階で、どれか1つに取り組めば完了と答えた。最後に「（関連：第1回）」と付いていた。
- `--trace` で見えたツール呼び出し（ツール名と引数）：「LoRAとQLoRAの違いは？」で `search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})`。用語を1つずつ検索していた。
- 1つの質問での LLM 呼び出し回数（`requests`）：2（`tool_calls` も2）。1回目の応答で検索を2つまとめて呼び、2回目でその結果を使って回答を書いていた。
- 追加したツールと、docstring に書いた説明：`make_quiz(lecture: int)`。用語集から指定した回の用語を1つ選び、「「○○」の意味は？」という問題と、その用語の定義を答えとして返す。docstring には「指定した回（1始まりの整数）の用語から確認問題を1問作り、問題と答えを返す。「第2回の確認問題を出して」のように、復習のための問題を求められたときに使う。」と書いた。用語が無い回（第0回など）を指定されたときは「用語集にありません」と返す。「第2回の内容から確認問題を1問出して」で `make_quiz({'lecture': 2})` が呼ばれ、「「QLoRA」の意味は？」と出題された。答えは書かずに「答えがわかったら教えてください」と返ってきた。

## 宿題

- 取り組んだレベル：基礎
- やったこと：用語集を検索するかどうかが、どこに書いた指示で決まっているかを見るために、2段階で変えた。
  1. `app/agent.py` の `INSTRUCTIONS` から「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。」の行を消した。
  2. 1 に加えて、`app/tools.py` の `search_glossary` の docstring から「AIエンジニアリングの用語や、この講座（AIE2026）に固有の言葉について答える前に使うこと。」の文を消した（`--list-tools` で、モデルに渡る説明から消えたことを確認）。

  元のままと、1・2 のそれぞれで、同じ2つの質問を `--trace` 付きで2回ずつ実行した。質問は、一般的な用語の「LoRAとQLoRAの違いは？」と、講座に固有の「AIE2026の講座の宿題にある「3レベル」とは何ですか？」。モデルは既定の gemini-3.5-flash-lite。
- 結果：

  | 状態 | LoRAとQLoRAの違いは？ | 「3レベル」とは？ |
  |---|---|---|
  | 元のまま | `search_glossary` を `'LoRA'` と `'QLoRA'` で1回ずつ、requests 2 | `search_glossary({'query': '3レベル'})`、requests 2 |
  | 1（指示の行を消した） | 同じ | 同じ |
  | 2（docstring の文も消した） | 同じ | 同じ |

  どの状態でも2回とも同じ呼ばれ方だった。回答もどれも用語集の定義に沿っていて、3レベルは基礎・実装・発展の3段階で、どれか1つで完了と答えた。違いは書き方くらいで、1 の状態の1回だけ「講座の用語集によると」で始まった。
- 気づき・疑問：
  - 「必ず確認する」という指示も、docstring の「答える前に使うこと」も消したのに、毎回検索してから答えた。ツール名や docstring の1行目（「講座の用語集から用語を検索し」）、`INSTRUCTIONS` の「用語集に見つからないことは〜」の行は残っているので、それだけで検索するものと受け取っているのだと思う。
  - 検索しなかったときに、第1回の素の LLM のような一般論に戻るのかを見たかったが、検索しない状態を作れなかった。検索させないようにするには「用語集を使わずに答える」と逆の指示を書く必要があるのか、が疑問として残った。

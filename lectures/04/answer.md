## 宿題

- 取り組んだレベル：基礎
- やったこと：採点のときに理由を先に書かせるか、判定を先に決めさせるかで、判定が変わるかを調べた。演習の STEP 3 で基準を直した後の状態から、次の2通りに変えて、同じ `lectures/04/labels.jsonl` に対して `uv run python -m app.judge` を2回ずつ実行した。比べる相手として、変える前の状態でももう1回実行した。
  1. `app/judge.py` の `CriterionVerdict` で、`reason` と `verdict` の順を入れ替える（判定が先）
  2. 1 に加えて、`build_judge` の出力の形式の指示（「reason（理由）を先に書き、そのあとで verdict を〜」）と、`rubric.md` の「先に理由を書いてから判定を決める」も、判定を先に決める書き方に変える
